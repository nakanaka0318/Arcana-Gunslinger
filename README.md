# Arcana-Gunslinger

## DOPATRIS — ドーパミンがドパドパ出るテトリス

`dopatris/index.html` をブラウザで開くだけで遊べます（依存なし・1ファイル）。

### 操作

| キー | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ / X | 右回転 |
| Z | 左回転 |
| ↓ | ソフトドロップ |
| Space | 流星ハードドロップ |
| C / Shift | ホールド |
| B / Backspace | 前に置いたミノを破壊（20秒に1回） |
| P / Esc | ポーズ |
| M | サウンドON/OFF |

スマホでは盤面を直接タッチして遊べます：タップで回転（左半分⟲／右半分⟳）、左右ドラッグで移動、下スワイプでハードドロップ、上スワイプでホールド。画面下のボタンでも操作できます。

### 普通のテトリスと違う10のこと

1. **フィーバータイム** — ゲージ満タンで10秒間スコア3倍。ブロックが虹色に光り、BGMが加速する。
2. **無限コンボ倍率** — 連続で消すたび倍率が+0.5ずつ上がり続け、効果音の音程もどんどん上がる。
3. **ゴールデンブロック** — 金色のマスを含む列を消すと +1000×Lv、コインが噴き出す。
4. **ボムブロック** — 着地した瞬間に周囲3×3を吹き飛ばす。ボム同士は誘爆する。
5. **ラッキースロット** — ライン消去のたびにスロットが回る。777でジャックポット＆即フィーバー、★★★で次の3個が金、♥♥♥で次がボム。
6. **流星ハードドロップ** — 光の軌跡を残して落下し、落下距離×2×Lvのボーナス。
7. **褒め言葉と画面演出** — 「ナイス!」「神!!」のポップアップ、画面シェイク、フラッシュ、パーティクル。
8. **セカンドチャンス** — 1回だけゲームオーバーを回避。上半分が大爆発して続行できる。
9. **実績アンロック** — プレイ中に11個のトロフィーが次々と解除される。
10. **レベルごとのテーマチェンジ** — レベルが上がるたびに背景色とBGMのキーが変わり、テンポも上がる。

### 連鎖システム（考えなくても連鎖する）

- **穴ができない**：ミノが着地するたびに、ブロックが下の隙間へ沈む。
- **同じ色で消える**：同じ色の仲間が6個以上つながると POP して消える（CASCADE TIME中は5個）。
  - 色の仲間：青（I・J）／暖色（O・L）／赤紫（Z・T）／緑（S）。
- **連鎖ペイント**：POPした周りのブロックや、消えたラインのすぐ上の段が1色に塗り替わり、落ちて次のPOPになりやすい。
- **2段目以降は1個少なくても消える**ので連鎖が続きやすい。
- **連鎖ごとにスコア倍率アップ**：2連鎖以上で連鎖ボーナス、4連鎖で即フィーバー、5連鎖以上で紙吹雪と拍手。
- **ゴーストが金色に光ったら置くだけ**：そこに落とすとラインかPOPが起きる合図。
- **連鎖アシスト**：次のミノは半分の確率で直前と同じ種類になる。

### BREAK（前に置いたミノを破壊）

- BREAKボタン / B / Backspace で、最後に置いたミノのブロックを粉砕する（20秒に1回）。
- 壊れた穴に上のブロックが落ちてくるので、そこから連鎖することもある。
- 一手戻しは不具合報告があったため削除し、この機能に置き換えた。

### ごほうびの頻度アップ

- サプライズギフトはごほうびが途切れて9秒 → 6秒で発生。
- ランダムイベントの間隔は28〜42秒 → 18〜28秒。
- 宝箱は8ラインごと → 6ラインごと。
